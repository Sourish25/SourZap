# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security and privacy of SourZap very seriously. If you discover a security vulnerability or privacy defect, please do **NOT** open a public GitHub issue.

Instead, please report it privately:
1. Open a private security advisory through GitHub's Security Advisories tab on the repository.
2. Or contact the maintainers directly via email.

Please include:
- A description of the issue and potential impact
- Steps or proof-of-concept to reproduce the behavior
- Affected device configuration and Android version

We will review your report, acknowledge receipt within 48 hours, and work on a fix promptly.
